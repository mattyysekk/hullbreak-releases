# Hullbreak 3D

Download **hullbreak3d-…-setup.exe** from the [latest release](https://github.com/mattyysekk/hullbreak-releases/releases/latest)
and run it. The game installs itself (no admin rights needed) and puts a shortcut on the desktop.

From then on the game keeps itself up to date: every time it starts, it checks here for a newer version,
downloads it and installs it.
